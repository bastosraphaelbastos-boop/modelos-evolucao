# Modelos de Evolução

Modelos de texto de evolução clínica para preencher e copiar no prontuário eletrônico.

- **Gratuito**
- **Funciona sem internet**, no Windows (navegador Edge ou Chrome)
- **Não guarda dados de pacientes**: ao fechar, o que foi preenchido é apagado

> Ferramenta de apoio à escrita. Não é dispositivo médico, não faz diagnóstico nem sugere conduta e não substitui o julgamento clínico. O profissional revisa todo o texto antes de registrar no prontuário.

## ⬇️ [Baixar o app](../../releases/latest/download/Modelos-de-Evolucao.zip)

## Como instalar (uma vez por computador)

1. Clique em **Baixar o app** (acima).
2. Abra a pasta **Downloads**, clique com o botão direito no arquivo **Modelos-de-Evolucao.zip** e escolha **Extrair tudo**.
3. Abra a pasta extraída e dê dois cliques em **INSTALAR OU ATUALIZAR**.

Pronto: aparece o atalho **Modelos de Evolução** na área de trabalho.

**Se aparecer "O Windows protegeu o computador"**: clique em **Mais informações** e depois em **Executar assim mesmo**. O aviso aparece porque o arquivo veio da internet; o instalador só copia o app para `C:\ModelosEvolucao` e cria o atalho, sem instalar nada no sistema. Se o computador  bloquear, peça ao responsável pela informática.

## Como atualizar

Baixe de novo pelo mesmo link e repita os passos. **Seus modelos são mantidos.**

## Dúvidas

O app tem uma **Ajuda** completa (botão **❓ Ajuda** no topo). O arquivo **LEIA-ME** e o **guia em PDF** vêm junto no download.
